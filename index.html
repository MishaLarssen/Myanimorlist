ซิงค์ข้ามเครื่อง

ซิงค์ผ่าน Secret Gist ในบัญชี GitHub ของคุณ สร้างโทเคนแบบ Classic ที่ GitHub → Settings → Developer settings → Personal access tokens (classic) โดยติ๊กสิทธิ์ gist อย่างเดียว แล้ววางโทเคนเดียวกันในทุกเครื่อง

ชื่อคลังและแบนเนอร์
